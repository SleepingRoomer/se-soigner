# Se soigner en France

Les droits santé des personnes précaires, notamment étrangères (PUMa, C2S, AME, PASS), un simulateur et les lieux de soin près de chez soi, en cinq langues. Projet de Soigner ou Saigner.

`lieux.json` est construit à partir de l'annuaire FINESS (ANS, data.gouv.fr, extraction du 12 mai 2026).

Prototype en cours de construction : contenus sourcés, pas encore relus par des spécialistes.

Site : https://sleepingroomer.github.io/se-soigner/ (une fois GitHub Pages activé dans Settings → Pages, branche main, dossier racine).
